# 2026 경북 초등 수업나눔축제 · 수다방 부스 안내 가이드

> **수학도 놀이다! AI 활용 수학 놀이터**
> 초등수학교육교사연구회 **“수다방”**

부스 방문 교사가 QR로 접속해 체험 내용을 빠르게 파악하고, 웹앱으로 바로 이동할 수 있는 안내 사이트입니다.

## 구성

```
index.html      랜딩 — 히어로 + 테이블1·2 진입 카드 + 부스 개요
table1.html     수학&코딩체험존 — 영상 임베드 + 체험 링크 + 활동 갤러리
table2.html     수학&동화제작소 — 영상 임베드 + 자료 링크 + 활동 갤러리 + 제작 순서
css/site.css    3개 페이지 공용 스타일
js/site.js      공용 스크립트 (효과음 · 스크롤 등장 · 라이트박스)
img/            웹용 최적화 이미지 (원본 130MB → 3.7MB)
assets/         원본 고해상도 PNG (git 제외, 로컬 보관)
PROPOSAL.md     제작 제안서
```

## 특징

- **3페이지 구조** — 랜딩에서 두 부스 중 하나로 바로 이동, 각 페이지가 짧아 드래그 없이 한눈에 파악
- **영상 우선 배치** — 각 부스 페이지 상단에 안내 영상을 바로 재생, 그 아래 체험 링크 버튼
- **반응형** — 스마트폰 1단 / 태블릿 2단 / 데스크톱 3~5단, `clamp()` 유동 타이포
- **애플 감성** — 유리 재질 네비, 넉넉한 여백, 스크롤 등장 애니메이션, 다크모드 자동 대응
- **효과음** — Web Audio API로 톤 생성(음원 파일 없음). 우하단 🔊 버튼으로 on/off, 설정 저장(페이지 간 공유)
- **안내판 라이트박스** — 인포그래픽 탭 시 전체 화면으로 확대
- **접근성** — `prefers-reduced-motion` 존중, 탭 타겟 44px 이상, 인쇄용 스타일 포함

## 로컬 실행

`index.html`을 브라우저로 열면 끝입니다. 빌드 과정이 없습니다. 단, YouTube 임베드는 `file://`에서 오류 153(플레이어 구성 오류)을 표시할 수 있습니다 — 실제 도메인(Vercel 배포)에서는 정상 재생됩니다.

## 이미지 최적화 방법 (재생성 시)

```
sips -s format jpeg -s formatOptions 72 -Z 2000 "assets/원본.png" --out "img/결과.jpg"
```
